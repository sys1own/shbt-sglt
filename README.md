# Static Holographic Boundary Theory (SHBT) — Synthetic Gravitational Lensing Telescope (SGLT) Simulation Stack

Implementation of the Static Holographic Boundary Theory Synthetic Gravitational Lensing Telescope (`shbt-sglt`) based on the engineering blueprint (`sglt.pdf`). The workspace integrates a multi-crate Rust core, a freestanding C11 microkernel (`shbt-os`), Automated Electronic Design (EDA) layout generators, PyO3 FFI bindings, and a Python orchestration CLI and telemetry HUD.

---

## Technical Overview

The SGLT synthesizes an artificial gravitational lens at Sun-Earth L2 via a two-spacecraft formation (Lens Craft and Sensor/Focal Craft). An effective point-mass perturbation of $M_{\text{seed}} = 10^{-6} M_{\odot}$ is generated by controlling boundary-state excess $\Delta N_0 = 7.5426 \times 10^{44}\text{ bit}$, producing a thin-lens focal baseline of $f_0 = 169.30\text{ m}$ for an impact parameter $r_0 = 1.000\text{ m}$.

### Primary Architectural Subsystems

* **Relativistic Metric Physics (`sglt-core-metric`)**: Computes linearized $3+1$ ADM metric foliations, enforces the holographic transport stability condition ($\vert{}\delta\mu\vert{} \le 1.0 \times 10^{-12}$), models multi-seed metric superposition using 512-bit arbitrary-precision floating-point arithmetic (`rug`/MPFR), and calculates non-paraxial eikonal pre-distortion for beam steering across $\Theta_{\text{tilt}} \in [0^{\circ}, 15^{\circ}]$.
* **Transducer & Acoustic FEA (`sglt-transducer-fea`)**: Models the $8 \times 8$ InP/InGaAs Heterojunction Bipolar Transistor (HBT) transducer array ($50.0\ \mu\text{m}$ pitch) with superconducting Niobium bias routing ($T_c = 9.20\text{ K}$), single-crystal sapphire acoustic transport ($44.178\text{ MRayl}$), and nanoporous silica aerogel ($d_m = 6.395\text{ nm}$) quarter-wave matching to the liquid Helium-4 ($4.20\text{ K}$) bath.
* **LANR Power & Fault Derating (`sglt-lanr-power`)**: Manages the 1,800-module Lattice-Assisted Nuclear Reaction (LANR) cluster delivering $913.176\text{ kW}_{\text{net}}$ ($33.804\%$ TEG efficiency) with $N+14$ module redundancy above the $1,786$-module debt threshold ($906.000\text{ kW}$). Implements the $N-k$ fault-derating protocol ($\Delta N = \lfloor \Delta P_{\text{net}} / P_{\text{bit}} \rfloor$) and fifth-order minimum-jerk focal repositioning trajectory generation up to $f = 1692.99\text{ m}$.
* **Bare-Metal Microkernel (`kernel/` & `sglt-hil-microkernel`)**: Freestanding C11 runtime (`shbt-os`) mapped to physical base address `0x70000000` (SHBT-MMIO-1). Features a statically allocated 2,112-byte `.stinespring_frame` SRAM frame, Hamming(72,64) SECDED ECC with AVX-512 Givens-rotation channel remapping, a 1.412 ns AVX-512 SIMD shunt interlock, 9.24 ns post-quench recovery execution, and lock-free zero-copy POSIX shared-memory telemetry transport ($0.561\ \mu\text{s}$ latency).
* **Flight GNC & Laser Metrology (`sglt-flight-gnc`)**: Simulates dual-wavelength heterodyne laser interferometry ($\lambda_1 = 1064.500\text{ nm}, \lambda_2 = 1064.520\text{ nm}, \lambda_{\text{syn}} = 56.6583\text{ mm}$) achieving $0.144\text{ pm}/\sqrt{\text{Hz}}$ range noise and $11.38\text{ nrad}$ Differential Wavefront Sensing (DWS) attitude knowledge. Executes a two-tier hybrid controller combining $\text{EMI-BF}_4$ electrospray microthrusters ($I_{\text{sp}} = 3200\text{ s}$) for SRP/tidal trim with electro-optic phase shifters for $0.1\text{ Hz} - 100\text{ kHz}$ jitter rejection.
* **Astronomical Image Reconstruction (`sglt-astro-reconstruction`)**: Regularized modified Richardson-Lucy deconvolution for the synthesized $D_{\text{eff}} = 2.00\text{ m}$ aperture, achieving angular resolution $\theta_{\text{res}} = 0.06289''$ and Strehl ratio $S \ge 0.999999984$.

## Hardware Architecture Specifications

### SHBT-MMIO-1 Core Register Block (`0x70000000`)

| Address | Symbol | Access | Width | Description |
| --- | --- | --- | --- | --- |
| `0x70000000` | `CR0_CTRL` | R/W | 32 bit | System control, mode select, phase arm, soft reset |
| `0x70000004` | `SR0_STAT` | R | 32 bit | Lock status, thermal alarm, metrology valid, shunt latch |
| `0x70000008` | `DET_MU_HI` | R | 32 bit | Upper 32 bits of signed Q1.62 eigenvector detuning $\delta\mu$ |
| `0x7000000C` | `DET_MU_LO` | R | 32 bit | Lower 32 bits of signed Q1.62 eigenvector detuning $\delta\mu$ |
| `0x70000010` | `BIT_OVF_H` | R/W | 32 bit | Upper word of 64-bit state overflow mantissa |
| `0x70000014` | `BIT_OVF_L` | R/W | 32 bit | Lower word of 64-bit state overflow mantissa |
| `0x70000018` | `RF_PHASE_V` | R/W | 32 bit | Channel address `[31:16]` and 16-bit DAC voltage code `[15:0]` |
| `0x7000001C` | `SHUNT_TRIG` | W | 32 bit | Nonzero write immediately fires solid-state shunt interlock |
| `0x70000020` | `REC_SEQ_PC` | R/W | 32 bit | Recovery sequencer entry point PC / terminal state code |
| `0x70000024` | `ECC_SYNDROME` | R | 32 bit | Latest SECDED syndrome and error classification flags |
| `0x70000028` | `ECC_CORR_ADDR` | R | 32 bit | SRAM word address of most recent SECDED correction |
| `0x7000002C` | `REMAP_SRC` | R/W | 32 bit | Failed logical channel ID and remapping generation index |
| `0x70000030` | `REMAP_DST` | R/W | 32 bit | Replacement physical channel ID and Givens rotation slot |
| `0x70000034` | `IRQ_MASK_ACK` | R/W | 32 bit | Interrupt mask control and write-one-to-clear status ack |

## System Requirements & Prerequisites

### Native System Dependencies

* **Toolchain**: Rust $\ge 1.83$, GCC with AVX-512 support (`-mavx512f`), Python $\ge 3.10$.
* **Libraries**: GNU Multiple Precision Arithmetic Library (`libgmp-dev`), MPFR (`libmpfr-dev`), MPC (`libmpc-dev`), M4 macro processor (`m4`).
* **Python Packages**: `numpy`, `streamlit` (for telemetry HUD visualization), `maturin` / `pyo3` (for native FFI builds).

## Build, Test & Execution Workflows

### 1. Bare-Metal Kernel Build

Compile the freestanding C microkernel into a shared library interface for the Rust HIL crate:

```bash
python python/shbt_sglt/cli/main.py build-kernel

```

*Output target*: `crates/sglt-hil-microkernel/bin/shbt_reference.so`

### 2. Workspace Test Execution

Run the complete Rust workspace test suite across all 6 domain crates:

```bash
cargo test --workspace

```

### 3. Comprehensive Verification & HIL Latency Suite

Run the master test harness orchestrator, executing Rust integration suites, C microkernel SIMD latency benchmarks, and POSIX shared-memory performance tests:

```bash
python tests/run_all_tests.py

```

### 4. Multi-Domain Co-Simulation Run

Execute a full mission timeline simulation (e.g., 3,600 seconds) covering GNC trajectory propagation, LANR power equilibrium, metric field synthesis, and microkernel HIL interlocks:

```bash
python python/shbt_sglt/cli/main.py sim --duration 3600

```

### 5. Automated EDA Export

Generate the $8 \times 8$ HBT lithographic GDSII mask and the 12-layer RF interposer Touchstone S-parameter file:

```bash
python python/shbt_sglt/cli/main.py export-eda

```

*Output targets*:

* `eda/masks/hbt_array.gds`
* `eda/rf/interposer.s2p`

### 6. Full System Audit & Verification Matrix Report

Execute the integrated 18-gate verification audit and generate a JSON report:

```bash
python python/shbt_sglt/cli/main.py verify --suite full-audit --json-report verification_matrix.json

```

### 7. Interactive Telemetry HUD

Launch the Streamlit interactive real-time dashboard:

```bash
streamlit run python/shbt_sglt/dashboard_hud.py

```
